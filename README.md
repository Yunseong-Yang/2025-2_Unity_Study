# 2025-2 Unity 2D 멘토링

> 2025년 2학기 게임 개발 동아리에서 진행한 Unity 멘토링용 예제 프로젝트입니다.
> 멘토로서 커리큘럼을 구성하고, 수업 자료·실습·과제를 제작해 대면 스터디를 운영했습니다.

## 멘토링 개요

- **역할:** Unity 멘토 — 커리큘럼 구성, 수업 자료·실습·과제 제작, 대면 진행
- **목표:** Unity의 주요 컴포넌트를 활용해 하나의 2D 게임을 단계적으로 구현
- **학습 범위:** Unity 개요, C# 스크립트, Game Lifecycle, Input, Animation, Collision, Object Setting, UI
- **저장소 구성:** 수업에서 사용한 단계별 예제 씬과 스크립트

이 저장소는 멘토링 당시의 교육 자료와 예제 코드를 보존하기 위한 기록용 저장소입니다. 현재는 Unity 실행 환경을 별도로 유지하지 않습니다.
